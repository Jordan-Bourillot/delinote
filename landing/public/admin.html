⚙️ Configuration (à faire une fois)
  1. Netlify env vars — depuis le dossier landing/ :
    netlify env:set STRIPE_SECRET_KEY "sk_live_..."
netlify env:set STRIPE_WEBHOOK_SECRET "whsec_..."
netlify env:set ADMIN_TOKEN "$(node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))")"
  2. Stripe webhook — Dashboard → Developers → Webhooks → Add endpoint :
    • URL : https://delinote.triskell-studio.fr/api/stripe-webhook
    • Events : checkout.session.completed, checkout.session.async_payment_succeeded, charge.refunded
    • Copier le « Signing secret » (whsec_…) → mettre dans STRIPE_WEBHOOK_SECRET
  3. Re-déployer : netlify deploy --prod --dir=. depuis landing/
  4. Tester : depuis Stripe Dashboard, "Send test webhook" sur ton endpoint → cette page doit afficher la conversion test.
