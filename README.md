# DéliNote

> Application de prise de notes locale, 100 % offline, sans télémétrie.

DéliNote est une app Electron de prise de notes développée par **[Triskell Studio](https://triskell-studio.fr)**.

- 📝 Notes riches (Tiptap), carnets, étiquettes, pièces jointes
- 📅 Agenda, tâches, contacts (avec WhatsApp), médicaments
- 🔍 Recherche floue, liens wiki `[[…]]`, backlinks
- 🎨 4 thèmes (clair, sombre, sépia, caraïbes)
- 🔐 Chiffrement AES-GCM, 100 % local — tes notes restent dans `%APPDATA%\delinote\`
- 🇫🇷 Français par défaut + anglais

## Téléchargement

Récupère la dernière version sur la page [**Releases**](https://github.com/Jordan-Bourillot/delinote/releases) :

- `DeliNote Setup X.X.X.exe` — installeur Windows (recommandé)
- `DeliNote X.X.X.exe` — version portable (un seul exe, pas d'installation)
- `DeliNote-X.X.X-win.zip` — archive zip

## Mises à jour automatiques

À partir de la version 0.9.0, DéliNote vérifie automatiquement les mises à jour au démarrage et te propose de les installer en un clic — plus besoin de réinstaller manuellement.
